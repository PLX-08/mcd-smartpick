# 陌生电脑演示操作手册 · McSmartPick

> 目标：**在任意一台陌生电脑上，向任何人证明「本项目真的接入了麦当劳官方 MCP」**。
> 核心思路：演示分三个场景，按现场条件选一条路走；**任何场景都有不依赖现场环境的兜底**。

---

## 0. 先决认知：三个场景与兜底顺序

| 场景 | 现场条件 | 演什么 | 说服力 | 翻车后果 |
|---|---|---|---|---|
| **A 实时链路** | 有网 + 有 Python + 带了 Token | 当场跑 `--live`，官方接口实时返回 | ⭐⭐⭐ 最高 | 降级到 B |
| **C WorkBuddy** | 现场电脑有 WorkBuddy 且能连 MCP 连接器 | 对话式调官方 MCP，工具调用过程可见 | ⭐⭐⭐ 高 | 降级到 B |
| **B 证据包** | 只有浏览器（任何电脑都有） | 单文件证据包：真实回包 + 可玩引擎 | ⭐⭐ 稳定 | 无（本场景不会翻车） |

**兜底顺序：A → B → C。** B 是地基——单个 HTML 文件、零依赖、双击即开，所以任何场景失败都往 B 降级。
**出发前把 B 准备好，A/C 是加分项。**

## 2. 场景 A：有网 + 有 Python + 带 Token —— 现场实时调用

**适合**：正式评审、技术面试、要「当场跑给你看」的场合。

### 操作步骤

1. 打开命令行，进入仓库目录，设 Token：
   ```bat
   set MCD_MCP_TOKEN=你的token
   ```
2. 跑实时链路（推荐这条，覆盖四段链路 + 官方核价）：
   ```bat
   python scripts/mcsmart.py --live --goal protein --budget 35 --city 宁波 --keyword 天一广场
   ```
3. 命令输出 JSON，边指边讲：
   - `store`：命中了哪家门店（含距离）→ 对应 `query-nearby-stores`
   - `items / items_codes`：实时菜单里的餐品编码 → 对应 `query-meals`
   - `live_price_check`：**官方核算的实付金额** → 对应 `calculate-price`，与本地算术逐分一致
   - 如果输出里出现 `nutrition_source: official`，顺便讲：官方不给营养字段时的兜底策略

### 讲法要点

- 「现在这一屏，是从麦当劳服务器**此刻**拉下来的。同样的命令，明天跑出来的价格可能不一样——这不是 bug，这正是它在用实时数据的证据。」
- 如果现场有第二台设备，可以同时打开证据包第 2 页，把实时输出和留档回包对照着讲。

### 翻车应对

| 翻车 | 现象 | 应对 |
|---|---|---|
| 没网 / 网被限制 | 命令卡住或超时 | 切手机热点；再不行直接降级 B |
| Token 失效 | 返回 401 / 鉴权失败 | 不解释技术细节，一句「Token 有时效，我们看留档证据」→ 降级 B |
| 现场电脑没 Python | `python` 不是内部或外部命令 | 降级 B（证据包不需要 Python） |
| 官方接口临时抽风 | 返回 5xx / 空数据 | 「服务端偶尔也会有波动，我们把成功时的完整回放留下来了」→ 降级 B |

> 降级话术要干脆，不纠缠：**「现场环境有限，我们直接看已经固化好的官方回放——数据一模一样，还带 traceId。」**

## 3. 场景 C：只有 WorkBuddy —— 用 MCP 连接器现场演

**适合**：对方也用 WorkBuddy，或评审方想看「Agent 怎么用工具」。

### 操作步骤

1. 确认 WorkBuddy 的 MCP 连接器已连接（麦当劳 MCP，授权状态正常）。
2. 直接用自然语言驱动，**把工具调用过程留在屏幕上**：
   - 「帮我查一下宁波天一广场附近的麦当劳门店」→ 展示 `query-nearby-stores` 调用与回包
   - 「这家店现在巨无霸多少钱？」→ 展示 `query-meals`
   - 「巨无霸加中薯条加可乐，帮我核个价」→ 展示 `calculate-price`
3. 每轮回包都能看到官方 `traceId`，顺手指出：「这个编号是麦当劳服务器返回的，可以追溯。」

### 讲法要点

- 这条路最像「未来的日常」：不说参数、不敲命令，说人话，Agent 自己调工具。
- 强调三层分工：「取数交给 MCP，算账交给代码，说话交给 Agent」——大模型不口算钱，是本项目的主张。

### 翻车应对

| 翻车 | 应对 |
|---|---|
| 连接器未授权 / 授权过期 | 当场重连；连不上就降级 B |
| 工具返回空（如券过期） | 正好用证据包第 2 页讲「券有生命周期，过期就消失」——翻车变教材 |
| 对方电脑没有 WorkBuddy | 降级 B |

## 4. 场景 B：只有浏览器 —— 证据包（兜底主场，重点练这条）

**适合**：任何没有把握的场合。**这是唯一 100 不会翻车的路径，优先级最高。**

### 操作步骤

1. 双击打开 `demo/evidence-pack.html`（先从 U 盘/邮箱/手机里找到它）。
2. 默认在「🚀 30 秒上手」页 → 点顶部第二个页签「🔴 真实链路证据」。
3. 从上往下讲，**两张牌按顺序打**：
   - **第一张「价格会涨」**：同款三件套，10-14 官方收 ¥49.00，10-18 收 ¥50.50 →「写死的数据不可能涨价，这是实时接口最硬的证据。」
   - **第二张「券会过期」**：10-18 那家店的券过期了，官方接口直接返回空数组 →「券也有生命周期，这同样假不了。」
4. 点开任意一条调用的「▸ 原始回包」，给想看 JSON 的人看原文。
5. 切到「🤖 引擎现场演示」页，点「健身增肌」一键示例 → **必须补一句**：「这页是离线示例数据，不调接口；真实数据在上面那页。」
6. 有人追问数字出处 → 切「📐 数据口径与边界」页，每个数字的出处都在表里。

### 讲法要点

- traceId 可以**点一下复制**，评委想验证就给他。
- 「本文件不联网、不需要装任何东西」这句话值得主动说——它本身就是工程态度的体现。

### 翻车应对

| 翻车 | 应对 |
|---|---|
| 浏览器打不开 / 版本太老 | 换 Edge 或 Chrome；都没有就放弃投影，把文件发给对方自己打开 |
| 文件忘带 | 邮箱附件 / 手机存储里各有一份；让对方加你微信/邮件当场发 |
| 投影屏幕小 | 证据包是响应式布局，凑近看也行；或只讲「证据一」「证据二」两张卡 |

## 5. 通用注意事项（比话术更重要）

1. **价格会变，主动说**。所有数字都是 2026-10-14 / 10-18 两个采集时刻的快照。现场实时跑出来的价格不同，不是出错——主动讲「价格以官方实时为准」，反而加分。
2. **券会过期**。证据包里那张「9.9元中杯冰美式」有效期至 **2026-10-20**；过期后如果要演用券链路，需要换门店/换券重新采集（先查 `query-store-coupons` 哪家店有在有效期内的券）。
3. **不确定的数字不念**。被问住就说「这个我没实测过，不编」，然后翻到口径页看有没有。诚实是人设。
4. **不贬低大模型**。主张是「分工」不是「谁强谁弱」：大模型说人话最强，算钱最弱，所以算钱交给代码。
5. **每场演示控制在 3 分钟内**。证据打完就停，留时间给对方提问；讲太长反而稀释重点。

## 6. 三分钟完整脚本（A/C 场景同样适用，把「实时跑」替换对应步骤）

> 「这个项目叫麦门聪明点：你说一句『增肌，预算 35』，它去麦当劳官方接口拉实时菜单和优惠券，用代码算出最划算的组合，再讲成人话。
>
> 现在你们看到的是麦当劳官方服务器的真实回放（或：我现在当场跑一次）。每一行都带官方返回的 traceId，可以在麦当劳那边追溯。
>
> 最有意思的是这两行：同样的三件套，10 月 14 号官方收 49 块，10 月 18 号收 50 块 5。价格是会长大的——因为数据真的是实时拉下来的，不是写死在程序里的。
>
> 还有：10 月 14 号这家店有两张券，10 月 18 号再查，券过期了，官方直接返回空。券也有生命周期，这假不了。
>
> 算钱这件事，我们不让大模型口算，交给可测试的纯代码：官方金额单位是分，我们除以 100 再求和，跟官方核价逐分对齐。这有 187 个自动化测试盯着，其中 35 个直接拿官方真实回包当输入。
>
> 你们可以点一下这个引擎演示页玩一下——注意这页是离线示例数据，真实链路在上面。我的项目就讲到这里，看看大家有什么问题。」

## 7. 高频提问速答（详细版见证据包第 4 页）

| 问题 | 一句话答法 |
|---|---|
| 「数据真是实时的？」 | 「同一组合 4 天涨了 1 块 5，写死的数据做不到。traceId 可以在麦当劳侧追溯。」 |
| 「为什么不让 AI 直接算钱？」 | 「AI 说人话最强、算钱最弱。算账放进纯函数，可复现、可测试、可审计。」 |
| 「优惠券怎么用的？」 | 「实测发现门店券是『指定商品特价券品』不是满减券，挂普通商品会被官方拒绝。我们把每张券转成券品，先取券后价再参与组合优化。」 |
| 「和大模型自己答有什么区别？」 | 「它不口算、不编价格；官方核价和本地算术逐分一致，有 187 个测试盯着。」 |
| 「和麦当劳什么关系？」 | 「参赛作品，非官方产品；用的都是官方公开 MCP 接口，免费申请 Token。」 |
