核心设计原则

点餐最痛的三件事——吃什么、怎么点最划算、营养够不够。大模型擅长「说人话」，却不擅长「算价格」。本项目把这件事拆成清晰的三层。

一次点餐的完整链路

从一句话到一张可下单的清单：意图解析 → 取数 → 算术 → 表达 →（可选）官方核算。

① 用户

一句话需求

「我想增肌，预算 35 块」

② Agent

意图解析

SKILL.md 把需求转成 goal / budget 等参数

③ 取数层

麦当劳 MCP

query-nearby-stores / query-meals / query-store-coupons

④ 算术层

组合优化

smart_pick 约束内枚举最优 + best_coupon 选券

⑤ 表达层

人话结果

搭配 / 省钱 / 营养，并可调 calculate-price 官方核算

🔬 真实链路验证（已实跑，含 traceId）

不是纸面 Demo，也不是「PPT 里说接了」。下面是对 mcp.mcd.cn 一次真实调用的四段链路，每条都带官方返回的 traceId。

调用时间 2026-10-14 15:16 门店 宁波海曙区开明街餐厅 3330480 · 218m 城市 宁波 · 关键词 天一广场
验证项官方返回traceId
附近门店 宁波天一广场命中 5 家，最近 3330480 @ 218m e3cda57b675e68b951fc4226581d7e1c
实时菜单 巨无霸 1100=¥25.50、中薯条=¥13.50、可乐=¥10.00（均为官方 currentPrice） 8d9516ec67a133345d35e9c86bb753be
门店券 2 张：中薯条买一送一、王牌小食拼（均为「指定商品特价券品」） 80ffd2228890d2d6e13884d556bc6a19
官方计价 A 巨无霸+中薯条+可乐 = ¥49.00（与本地算术一致 ✅） ad938ccabd2ab90b7cc63887a4c78f7b
券后价 B 中薯条买一送一 ¥27 → ¥13.50（省 50%，得 2 份） c696cc16933004412fba555e10d2cc55
券后价 C 王牌小食拼 ¥22 → ¥15.90 4caf9089bb865a062ef27165ae4ae42d
关键建模发现：门店券是「指定商品特价券品」，不是满减券，且对应一张独立券品编码，无法挂在普通商品编码上。 实测把普通薯条 4810 配 couponId 去计价 → 返回 {"success":false,"code":600012,"message":"促销规则不支持该商品"}。 因此本项目把每张券统一转成「券品」：先逐张调 calculate-price 取券后实付价，再纳入组合优化——「用不用券、用哪张券」变成了算法问题。
